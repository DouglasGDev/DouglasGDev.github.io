# Douglas — Portfólio

Meu portfólio pessoal, hospedado no GitHub Pages: **https://douglasgdev.github.io**

Baseado no template [vCard](https://github.com/codewithsadee/vcard-personal-portfolio) (MIT).

## Stack em destaque

- **Backend & integrações:** Rust, Go, Java, PHP/Laravel, Node/Express, Delphi — REST com Swagger/OpenAPI, Webhooks, WebSocket e arquitetura BFF
- **Bancos de dados:** MySQL, PostgreSQL, Oracle, MariaDB, Redis
- **Web & mobile:** React, Next.js, React Native, JavaScript/TypeScript
- **IA aplicada:** LLM, MCP, RAG, n8n
- **Infra & DevOps:** Docker, AWS, CI/CD, noções de Kubernetes

## Rodando localmente

É HTML/CSS/JS puro — basta abrir o `index.html` ou servir com:

```bash
npx serve .
```
